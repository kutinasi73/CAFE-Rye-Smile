# CAFE-Rye&Smileサイト

## 概要
本作品は、架空のベーカリーカフェ「CAFE Rye & Smile」を題材にしたオリジナルWebサイト制作です。 
本作品では設計からデザイン・実装までを自分で考えるオリジナル制作に挑戦しました。 
UI実装・DOM操作・アニメーション表現の理解を深めることを目的としています。 
※ 学習目的の制作であり、商用利用はしていません。

## 工夫した点 
- ライブラリを使用せずVanilla JSのみで実装し、処理の流れを理解
- 構造（HTML）と見た目（CSS）、挙動（JS）を分離して管理
- ターゲットユーザーを想定し、余白や視認性を重視したUI設計

特にセクションごとに視認性を高める余白・レイアウト調整に時間をかけました。

---

## 苦労した点
