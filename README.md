# BEAMS Hello Baby 模写サイト

## 概要
BEAMS公式サイト「Hello Baby」特設ページを題材にした模写制作です。

## 実装内容

### レスポンシブ対応
- モバイル / タブレット / PC を想定
- メディアクエリによるレイアウト切り替え

### ハンバーガーメニュー
- JavaScriptでクラスを切り替え
- CSSでアニメーション制御

### アコーディオンメニュー
- クリックイベントによる開閉制御
